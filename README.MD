# Intelligent Knowledge Retrieval System

An AI-powered Retrieval-Augmented Generation (RAG) system that retrieves relevant information from uploaded documents and generates accurate responses using Large Language Models.

## Features
- PDF/Text document retrieval
- Semantic search using embeddings
- Context-aware response generation
- Fast and intelligent knowledge retrieval

## Technologies Used
- Python
- Google Colab
- LangChain
- FAISS
- Hugging Face
- LLMs

## Project Workflow
1. Upload documents
2. Convert text into embeddings
3. Store vectors in FAISS
4. Retrieve relevant chunks
5. Generate AI-based answers
